# Заявки «Замовити рекламу» → Telegram

Сайт надсилає бриф на `POST /api/ad-request`, а сервер пересилає його адміністраторам через бота радіо.

## Налаштування (Render → Environment)

| Змінна | Значення |
|---|---|
| `ADS_CHAT_ID` | Кому надсилати заявки: ID користувача або групи. Кілька — через кому: `123456789,-1001234567890` |

Як дізнатися ID:
- **Особисто:** напишіть боту радіо `/start`, потім `/chatid`. Бот відповість вашим ID.
- **Група менеджерів:** створіть групу, додайте туди бота й напишіть у групі `/chatid`. ID групи починається з `-100…`.

Бот може писати лише тим, хто хоч раз написав йому `/start`, або в групи, де він учасник.

## Що перевіряє сервер

- обов'язкові поля: ім'я, телефон (мінімум 7 цифр), хоча б один тип реклами;
- не більше 5 заявок з однієї IP-адреси за 10 хвилин;
- приховане поле-пастка `website` від спам-ботів;
- довжина полів обмежена, HTML у тексті екранується.

## Відповіді

`200 {ok:true}` — надіслано · `400` — не заповнено поля · `429` — забагато заявок · `503` — не задано `ADS_CHAT_ID` · `502` — Telegram не прийняв повідомлення.
